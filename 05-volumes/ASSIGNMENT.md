# Docker Volume

Источник: https://app.simulative.ru/course/34/1707

Создать образ PostgreSQL; проверить потерю доступа к данным при новом контейнере без явного тома, а затем сохранение с anonymous volume, named volume и bind mount. В условии предложено подключаться через PgAdmin. Опубликовать образ и приложить файлы.
